0.0.0 - Initial
===============

This is an initial release of etllib supporting capability for
reformulating JSON data using Tika_ and JSON read/write in prep
for ETL using Apache OODT into Solr_. Those workflows now run
on Mnemosyne_, the continuation of Apache OODT after the ASF
retired it to the Attic in 2023.


.. References:
.. _Mnemosyne: https://github.com/chrismattmann/mnemosyne
.. _Tika: http://tika.apache.org/
.. _Solr: http://lucene.apache.org/solr/
